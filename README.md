# particle-twister

This is the code base for Particle Twister progressive web app (PWA) hosted at https://particle-twister.mehlhase.info/.

Find more details, plans and a description at https://sascha.mehlhase.info/particle-twister/ as well as on https://particle-twister.web.cern.ch/.

For question and inquries about the game and especially on the PWA, please refer to contact me via <kontakt@mehlhase.info>.
